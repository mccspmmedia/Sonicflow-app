# SonicFlow 🎵

iOS app for meditation, sleep and relaxation with a powerful sound mixer. Built for the US market.

## Features
- 80+ relaxation and meditation sounds
- Sound mixer — create your own combinations
- Timer with auto-stop
- Reminders and notifications
- Categories: meditation, sleep, relaxation, focus

## Stack
- Swift
- Xcode
- AVFoundation
- iOS 15+
